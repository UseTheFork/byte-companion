name: III. You Aren't Gonna Need It (YAGNI)
order: 3
---
Code MUST only be written to satisfy current, concrete requirements — never on speculation of future needs. Abstractions, configuration options, and extension points MUST NOT be introduced until a real use case demands them. Dead code MUST be removed before the feature branch is merged.
